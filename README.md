# Tempo Landing Site

One-page marketing site for tempo: calm calendar.

Live URL after deploy: `https://yahmez3.github.io/tempo/`

## Stack
- Plain HTML/CSS, no framework, no build step
- GitHub Pages serves `index.html` directly
- Assets in `/assets/`

## Deploy (one-time)
See `PUSH_INSTRUCTIONS.md` for the exact commands. Summary:
1. Create public GitHub repo `Yahmez3/tempo`
2. Push this folder
3. Enable GitHub Pages (Settings → Pages → Source: `main` / root)
4. Wait ~2 min, then visit https://yahmez3.github.io/tempo/

## Updating
Edit `index.html`, commit, push. GitHub Pages rebuilds in ~60 seconds.
